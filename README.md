# neulbo
늘보 - 수면 관리 시스템

🦥서비스 개요

1. 불규칙한 수면 패턴을 가진 사용자를 위해, 수면 데이터를 시각적으로 제공하여 자가 개선을 위한 인사이트를 제공하는 애플리케이션입니다.
2. 웨어러블 기기와 스마트폰을 통해 수면 데이터를 수집하고, 이를 기반으로 시각적인 데이터 분석 및 수면 단계(레벨) 판단 기능을 제공합니다.
3. 또한, 수면 커뮤니티 기능을 통해 사용자들 간의 수면 챌린지, 랭킹 시스템 등을 운영하여 건강한 수면 습관 형성을 목표로 합니다.
